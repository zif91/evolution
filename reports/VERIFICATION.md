## Ограничения

- Это локальная проверенная ветка, а не гарантия совместимости каждого плагина. Конкретная production-база и набор пользовательских дополнений не предоставлялись.
- Commerce, PageBuilder, сторонние платёжные модули, реальная отправка SMTP, Redis, очереди, PostgreSQL/MariaDB и многопользовательская нагрузка не проверялись.
- Docker недоступен: код/шаблоны локального Salo fork обновлены, но сборка контейнера не подтверждена.
- При проверке загрузки классов пропущен один существовавший upstream интерфейс `EvolutionCMS\Interfaces\DatabaseInterface`: он наследует интерфейс отсутствующего в исходном Composer-пакете `AgelxNash\Modx\Evo\Database`. Рабочий DBAPI Evolution этот интерфейс не реализует. Остальные классы ядра загружены; результат в `classes.log`.
- Синтаксическая проверка PHP — `php-lint.json`. Она не заменяет функциональные сценарии.
- Прямые вызовы удалённых API Illuminate 8/Flysystem 1, старые ограничения Composer, изменения Carbon 3 требуют аудита расширений. Слой совместимости сохраняет API Evolution в проверенных сценариях.
- Production не изменён. Работа опубликована в форке; PR внутри форка предназначен для обсуждения, upstream PR не отправлялся.

## Воспроизведение и артефакты

См. `../UPGRADE-LARAVEL-13.md`. JSON-отчёты, снимки и логи оставлены локально и исключены из Git. Для публичного ревью опубликован этот сводный отчёт; CI прикладывает JSON результатов своих запусков. Секреты и SQL-дампы хранятся только в `.local/`, исключённой из Git и закрытой router-ом.

## Дополнение: PR #543 + DocumentManager #1

Авторские PR интегрированы совместно; подробности, SHA и границы — [PR543-INTEGRATION.md](../docs/PR543-INTEGRATION.md).
На итоговом совместном коде локально подтверждены **31 базовая + 19 DocumentManager + 14 HTTP проверок**, а также **10 браузерных сценариев**. PHP lint: 58 изменённых/тестовых файлов, ошибок нет. HTTP-сценарии проверяют как администратора, так и редактора без прав публикации/доступа к закрытым TV и ресурсам. Проверки мутаций сверяют фактическую БД; временные данные удаляются. Новые события добавлены в локальную БД без переименования существующих ID.

Обнаруженные регрессии имеют воспроизводящие тесты и отдельные исправления; отсутствие конфликтов Git само по себе не считалось подтверждением совместимости. Полное покрытие всех изменённых процессоров не заявляется. Apache/Nginx rewrite в HTTP-наборе не проверяется (`seostrict` временно выключается и восстанавливается).
